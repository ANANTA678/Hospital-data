# 🏥 U.S. Healthcare Analytics Dashboard (2019–2020) – Power BI Project

## 📌 Project Overview

This project presents a comprehensive **Power BI dashboard** analyzing the **U.S. healthcare ecosystem** between **2019 and 2020**.

The dashboard is designed to deliver deep insights into:

* Financial performance 💰
* Hospital operations 🏥
* Patient behavior 👨‍⚕️
* Provider efficiency 📊

It transforms raw healthcare data into actionable insights that support **data-driven decision-making** for healthcare organizations.

---

## 🎯 Objectives

* Analyze healthcare expenses and revenue trends
* Monitor hospital performance and operational efficiency
* Understand patient demographics and outcomes
* Evaluate provider productivity and specialization
* Identify cost optimization opportunities

---

## 📊 Dashboard Modules

### 🔹 1. Executive Summary

A high-level overview of key performance indicators:

* 💰 **Total Expenses:** 13.0M
* 💵 **Insurance Revenue:** 7.5M
* 👨‍⚕️ **Patient Revenue:** 1.5M
* 🧑‍🤝‍🧑 **Total Patients:** 5117
* 📈 **Total Payments:** 9.0M

#### Key Insights:

* Monthly expense trends show fluctuations with peak periods
* Revenue vs expense comparison highlights profit gaps
* CPT unit distribution reveals procedure demand patterns

---

### 🔹 2. Hospital Analysis

Focuses on hospital-level performance and financial health:

* 🏥 **Total Hospitals:** 11
* 📊 **Procedure Count:** 239K
* 💳 **Accounts Receivable:** 4.0M

#### Key Visuals:

* ARGE Ratio Trend (financial efficiency)
* Inpatient-to-Outpatient Ratio
* Expense distribution by CPT grouping
* Hospital-wise performance metrics

#### Insights:

* Certain hospitals dominate procedure volumes
* Financial ratios indicate efficiency gaps
* Expense distribution is highly concentrated

---

### 🔹 3. Patient Outcome Analysis

Explores patient demographics and behavior:

* 👥 **Distinct Patients:** 5117
* 🌍 **States Covered:** 49
* 🏙️ **Cities:** 531
* 🎂 **Average Age:** 44

#### Analysis Includes:

* Lifestyle factors (Smoking, Alcohol, Diet, Exercise)
* Gender distribution
* Blood group analysis
* Geographic distribution of patients

#### Insights:

* Majority patients follow moderate lifestyle habits
* Patient distribution is dense in specific regions
* Blood group trends show dominant categories

---

### 🔹 4. Payer-Provider Analysis

Analyzes healthcare providers and payer relationships:

* 👨‍⚕️ **Providers:** 931
* 👨‍💼 **Employees (FTE):** 712
* 🏥 **Specialties:** 34

#### Key Visuals:

* Regional provider distribution
* Specialty-wise provider breakdown
* Monthly provider activity trends
* Performance matrix (CPT Units vs FTE)

#### Insights:

* Provider distribution varies significantly by region
* Some specialties dominate healthcare services
* Efficiency varies across provider categories

---

### 🔹 5. Financial Trend Analysis

Advanced financial tracking and optimization:

* 📉 Monthly gross vs adjusted expenses
* ⚙️ Adjustment factor simulation
* 📊 Cost optimization insights

#### Insights:

* Expenses show declining trend after early peaks
* Adjustment factor helps simulate financial scenarios
* Identifies opportunities for cost reduction

---

## 🎛️ Interactive Features

* Dynamic filters (Region, Gender, Hospital, Blood Group)
* Drill-down capabilities
* Cross-filtering across visuals
* Scenario analysis using adjustment sliders
